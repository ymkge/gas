# B列テキスト改行スクリプト

このGoogle Apps Script (GAS) は、Google スプレッドシートの指定したシートのB列にあるテキストを、50文字ごとに自動的に改行し、セルの折り返し表示を有効にするツールです。

🚀 使用方法
1. スプレッドシートを開く
- 改行処理を適用したいGoogle スプレッドシートを開きます。

2. スクリプトエディタを開く
- スプレッドシートのメニューバーから「拡張機能」>「Apps Script」を選択します。

3. コードを貼り付ける
- スクリプトエディタが開いたら、既存のコードがもしあればすべて削除し、main.gsの中身を貼り付けます。

4. コードを保存する
- スクリプトエディタ上部のフロッピーディスクのアイコン（プロジェクトを保存）をクリックしてコードを保存します。

5. スプレッドシートをリロードする
- スクリプトを保存した後、スプレッドシートのタブを閉じて再度開くか、ブラウザをリロード（再読み込み）します。

6. カスタムメニューから実行する
- スプレッドシートの上部に新しく「カスタムメニュー」という項目が追加されています。
- 「カスタムメニュー」をクリックし、「B列を50文字で改行」を選択します。

7.シート名を入力する
- 処理を実行したいシートの名前を入力するためのダイアログが表示されます。
- 正確なシート名を入力し、「OK」をクリックします。

8. 処理完了
- スクリプトが実行され、指定されたシートのB列のテキストが50文字ごとに改行されます。
- 処理が完了すると、メッセージボックスで通知されます。

⚠️ 注意点
- データのバックアップ: スクリプトを実行すると、B列の元の文章が改行された状態で上書きされます。 予期せぬ問題に備え、必ず実行前にスプレッドシートのバックアップを取っておくことを強くお勧めします。 または、コピーしたシートでスクリプトをテストしてください。
- シート名の正確性: スクリプトは指定されたシート名に基づいて動作します。シート名が正確でない場合、スクリプトはエラーとなり処理を実行できません。 大文字・小文字、スペースなども含め、シート名を正確に入力してください。
- ヘッダー行の考慮: 現在のスクリプトはB列の1行目から最終行までを処理します。もしB列の1行目がヘッダー（見出し）で、2行目からデータが始まる場合は、スクリプト内の以下の行を編集して開始行を調整してください。

```JavaScript

// 変更前
const range = sheet.getRange("B1:B" + lastRow);

// 変更後（例: 2行目から開始する場合）
// const range = sheet.getRange("B2:B" + lastRow);
```
- 処理時間: B列に非常に多くの行（数万行以上）のデータがある場合、スクリプトの処理に時間がかかることがあります。Google Apps Scriptには実行時間制限（通常6分）があるため、制限時間内に処理が完了するか確認してください。
- 初回実行時の承認: スクリプトを初めて実行する際には、Googleアカウントによるスクリプトの承認を求められます。画面の指示に従って承認を進めてください。
