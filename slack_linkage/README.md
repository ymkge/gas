# 案件依頼Slack通知スクリプト

## 概要

このプロジェクトは、Googleスプレッドシートの特定の列（A, B, C, D列）にすべて値が入力されたことをトリガーとして、指定したSlackチャンネルに通知を送信するGoogle Apps Script（GAS）です。

## 機能

-   **自動通知**: Googleスプレッドシートの指定した行のA〜D列が全て入力されると、自動でSlackに通知します。
-   **動的なメッセージ生成**: 通知メッセージには、入力された行のデータ（エントリー日付、依頼概要など）が自動で挿入されます。
-   **設定の容易さ**: スクリプト内の簡単な設定と、GUIベースのトリガー設定で導入が可能です。

## セットアップ手順

設定は大きく分けて「Slack側の設定」と「Google Apps Script側の設定」の2つです。

### ステップ1: Slack Incoming Webhookの準備

GASからSlackにメッセージを送信するための「接続URL（Webhook URL）」を取得します。

#### 1. Slackアプリの作成

1.  [Slack API](https://api.slack.com/apps) のページにアクセスし、`Create New App` をクリックします。
2.  `From scratch` を選択します。
3.  `App Name`（例: `案件依頼通知`）を入力し、対象の `Workspace` を選択して `Create App` をクリックします。

#### 2. ボット情報と権限の設定

1.  アプリ管理画面の左側メニューから **App Home** をクリックします。
2.  `App Display Name` の項目で、ボットの表示名（例: `案件依頼通知ボット`）を設定します。
3.  次に、左側メニューから **OAuth & Permissions** をクリックします。
4.  `Scopes` セクションまでスクロールし、`Bot Token Scopes` に以下の2つの権限（スコープ）を追加します。
    -   `chat:write`: アプリがチャンネルにメッセージを投稿する権限
    -   `incoming-webhook`: Webhookを利用する権限

#### 3. アプリのインストール

1.  **OAuth & Permissions** ページの上部に戻り、`Install to Workspace` をクリックします。
2.  権限の許可を求める画面が表示されるので、`許可する` をクリックします。

#### 4. Webhookの有効化とURL取得

1.  左側メニューから **Incoming Webhooks** をクリックし、`Activate Incoming Webhooks` のスイッチを **On** にします。
2.  ページ下部の `Add New Webhook to Workspace` をクリックします。
3.  メッセージを投稿したいチャンネル（例: `#kyouyuu`）を選択し、`許可する` をクリックします。
4.  **Webhook URL** が生成されるので、`Copy` ボタンでURLをコピーします。このURLは後のステップで使います。

### ステップ2: Google Apps Script (GAS) の準備

1.  通知の起点となるGoogleスプレッドシートを開きます。
2.  上部メニューの `拡張機能` > `Apps Script` をクリックして、GASエディタを開きます。
3.  エディタに最初から書かれているコードをすべて削除し、`src/main.gs` の内容を貼り付けます。
4.  スクリプトの冒頭にある `SHEET_NAME` の値を、ご自身のシート名に合わせて変更してください。
    ```javascript
    // 監視対象のスプレッドシート名を設定してください
    const SHEET_NAME = 'シート1'; // 例: '案件依頼台帳'
    ```
5.  `Ctrl + S` またはフロッピーディスクのアイコンをクリックして、プロジェクトを保存します。

### ステップ3: Webhook URLをスクリプトプロパティに設定

取得したWebhook URLを、コードに直接書き込まずに安全に設定します。

1.  GASエディタの左側メニューから、**プロジェクトの設定**（歯車アイコン⚙）をクリックします。
2.  `スクリプト プロパティ` という項目で `スクリプト プロパティを追加` をクリックします。
3.  以下の通り入力し、`スクリプト プロパティを保存` をクリックします。
    -   **プロパティ**: `SLACK_WEBHOOK_URL`
    -   **値**: **ステップ1**でコピーしたSlackのWebhook URL

### ステップ4: トリガーの設定

スプレッドシートが編集されたときにスクリプトが自動実行されるように設定します。

1.  GASエディタの左側メニューから、**トリガー**（目覚まし時計アイコン⏰）をクリックします。
2.  右下の `トリガーを追加` ボタンをクリックし、以下のように設定します。
    -   **実行する関数を選択**: `checkAndNotifySlack`
    -   **実行するデプロイを選択**: `Head`
    -   **イベントのソースを選択**: `スプレッドシートから`
    -   **イベントの種類を選択**: `編集時`
3.  `保存` をクリックします。

### ステップ5: 権限の承認

トリガーを初めて保存する際に、スクリプトの実行許可を求められます。

1.  ご自身のGoogleアカウントを選択します。
2.  「このアプリはGoogleで確認されていません」という警告が表示された場合は、`詳細` をクリックし、`（プロジェクト名）（安全ではないページ）に移動` を選択します。
3.  スクリプトがスプレッドシートや外部サービスへ接続することを許可するため、`許可` をクリックします。

以上ですべての設定は完了です。

## 使い方

1.  設定対象のスプレッドシートを開きます。
2.  任意の行のA列からD列にかけて、値を入力していきます。
3.  D列のセルに入力が完了した時点で、指定したSlackチャンネルに通知メッセージが自動で投稿されます。
